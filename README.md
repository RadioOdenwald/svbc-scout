# SVBC Scout ⚽

Moneyball-Scouting-App für den SV/BSC Mörlenbach (Kreis Bergstraße).

**Live-App:** https://radioodenwald.github.io/svbc-scout/

- 180 Senioren-Torschützen (Kreisoberliga + Kreisliga A–D Bergstraße, Saison 2025/26)
- Formtrend vs. Vorsaison 24/25, Presse-Dossiers, 81 Jugend-Talente
- MScore-Bewertungsmodell mit verstellbaren Gewichten, 💎 Rohdiamanten, Kaderplaner

Datenquellen: FUSSBALL.DE (Tabellen & Torjägerlisten), Regionalpresse (WNOZ, MM), Vereinsseiten.
Nur für interne Vereinszwecke. Stand: Juli 2026.
